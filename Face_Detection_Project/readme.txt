
========================================
       FACE DETECTION PROJECT
========================================

1. PROJECT NAME:
Face Detection using Python and OpenCV

2. OBJECTIVE:
To detect human faces in images using
Python and OpenCV.

3. TECHNOLOGIES USED:
- Python
- OpenCV
- Haar Cascade Classifier

4. SOFTWARE REQUIREMENTS:
- Python 3
- VS Code
- OpenCV Library

5. INSTALLATION:

Open terminal and run:

pip install opencv-python

6. PROJECT FILES:

face_detection.py - Main Python program
image.jpg          - Input photograph
README.txt         - Project documentation

7. HOW TO RUN:

Step 1: Open project folder in VS Code.

Step 2: Open terminal.

Step 3: Install OpenCV.

Step 4: Run the command:

python face_detection.py

8. EXPECTED OUTPUT:

The program detects faces in the input
image and draws green rectangles around
each detected face.

The result is saved as output.jpg.

9. CONCLUSION:

The Face Detection project successfully
detects human faces in images using
OpenCV and Python.
